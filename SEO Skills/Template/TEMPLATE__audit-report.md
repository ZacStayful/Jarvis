## How to use this template

1. Copy the entire template
2. Replace each `[bracketed field]` with the actual audit data
3. Remove sections that don't apply (e.g. competitor backlink gaps if no tool access)
4. Deliver to the user

The closing statement is verbatim — do not modify.
